# IU3 Android

Читайте `README.md` и `openspec/changes/port-ios-to-android/` перед изменениями.

- Kotlin, Jetpack Compose, светлая и тёмная темы ИУ3 по системной настройке. Цвета и общие элементы находятся в `core:designsystem`.
- `app` собирает зависимости и навигацию. Feature-модули не зависят друг от друга.
- Экраны не читают файлы, DataStore и JSON. ViewModel фичей используют интерфейсы `core:data-api`; реализации скрыты в `core:data`. Обоснования — в `docs/architecture.md`.
- UI-строки находятся в ресурсах соответствующего модуля; тексты ответов API остаются в JSON.
- Используйте Navigation 3, сериализуемые ключи, отдельные стеки вкладок и entry decorators. Не отключайте пересоздание Activity ради сохранения состояния.
- Сохраняйте изменения незакоммиченными, пока пользователь не попросит коммит. Не отправляйте изменения в origin без запроса.
- До сборки нужно разрешение пользователя. Для текущего переноса debug-сборка разрешена. Тесты не добавлять и не запускать без отдельного запроса.
- Отдельно сообщайте о статической проверке, сборке и ручной проверке на эмуляторе. Не называйте непроверенные сценарии готовыми.

- Состояние данных и действия фичи принадлежат её ViewModel; `app` не подменяет её общей ViewModel всех экранов.
- Экраны находятся в `ui`, компоненты — в `ui.components`, ViewModel/UI state — в `presentation`, навигационные entrypoints — в `navigation`. Логику фичи размещайте в её модуле.
- Экран — первая функция своего файла, верхнеуровневые классы — в отдельных файлах. В объявлениях с более чем двумя параметрами каждый параметр находится на отдельной строке; неоднозначные аргументы называйте.
- Используйте штатный форматер Android Studio. Не форматируйте встроенные JSON и сгенерированные каталоги.
- Не переименовывайте старые классы Worker/receivers в `core:notifications` без миграции уже сохранённых задач Android.

- Wildcard-импорты запрещены; используйте явные импорты.

- Повторяющиеся настройки Gradle находятся в `build-logic`. Выбирайте convention-плагин application/library/api/feature и подключаемые compose/hilt/serialization; SDK и Java меняйте в `gradle/libs.versions.toml`.
- Межмодульные зависимости объявляйте через type-safe accessors (`implementation(projects.core.dataApi)`), сохраняйте их явными в модуле. Инструкция и примеры — `docs/build-logic.md`.
